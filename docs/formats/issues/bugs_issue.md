# Issue template for bugs

```text
## Bug Description

Provide a clear and concise description of the identified bug, specifying which functionality is affected and how it impacts the system.

## Steps to Reproduce

1. Navigate to...
2. Select...
3. Perform...
4. Observe the issue.

## Expected Behavior

Describe how the affected functionality should behave when working correctly.

## Actual Behavior

Describe what currently happens and how it differs from the expected behavior.

## Evidence

- **Screenshots or videos:** `[EVIDENCE]`
- **Console errors or logs:** `[LOGS]`
- **Affected URL:** `[URL]`

## Technical Information

- **Environment:** `Development / Production`
- **Browser:** `[BROWSER]`
- **Affected component:** `[COMPONENT]`
- **Severity:** `Low / Medium / High / Critical`

## Requested Fix

Describe what needs to be corrected to resolve the issue, without imposing a specific technical implementation when the root cause has not yet been identified.

- Fix the identified behavior.
- Preserve existing functionality.
- Avoid introducing issues in related components.

## Acceptance Criteria

- [ ] The reported bug has been fixed.
- [ ] The functionality behaves as expected.
- [ ] The fix has been verified using the reproduction steps.
- [ ] No regressions have been introduced in related functionality.
- [ ] The fix works correctly across the affected environments and devices.

```
