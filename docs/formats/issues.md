Indicate which element of the prototype needs to be modified and the expected outcome.

- **Link or screenshot:**

## Elements to be preserved

Specify which parts of the original design, structure, or behavior should not change.

## Acceptance criteria

- All requested modifications have been implemented.

- No errors were introduced in other components.
