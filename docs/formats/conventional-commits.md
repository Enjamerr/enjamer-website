# Commit Convention — enjamer - website

## Format

```text
type(scope): short description

- Detailed description of the change.
```

The detailed description is optional

## Project Scopes

- `docs`: Documentation changes.
- `component`: Changes to a component.
- `deps`: Dependency changes or updates.
- `ci/cd`: Continuous Integration or Continuous Deployment changes.
- `config`: Changes to the project's general configuration.
- `multiple`: Changes that span multiple scopes.
- `identity`: Adding a new developer identity to the project.

## Types

### Feature

```text
feat(scope): new functionality

- Description of the new functionality.
```

### Fix

```text
fix(scope): bug fix

- Description of the bug fix.
```

### Refactor

```text
refactor(scope): code refactoring

- Description of the refactoring.
```

### Chore

```text
chore(scope): Changes in users settings

- Description of the changes.
```
