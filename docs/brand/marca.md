# Marca Enjamer — referencia rápida para código

Fuente: Manual de Marca v1.0.0 (2026). Detalle completo en el PDF original.

## Símbolo

Tres hexágonos (enjambre): unión de ideas, conocimiento compartido y
crecer juntos.

- `public/brand/isotipo-oscuro.png` — fondos oscuros (centro integrado).
- Para fondos claros usar la versión con hexágono central definido.
- `public/brand/logotipo.png` — identidad completa (isotipo + ENJAMER).
- En web preferir PNG/SVG (transparencia).
